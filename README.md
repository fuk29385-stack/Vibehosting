# PawShop

PawShop — современный интернет-магазин для домашних питомцев. Сайт создан в минималистичном стиле и включает каталог товаров для собак, кошек, игрушек, аксессуаров, а также отдельную страницу с маленькими домашними питомцами.

## Что внутри

- Главная страница с hero-блоком, категориями и каталогом
- Фильтрация, поиск и сортировка товаров
- Корзина с изменением количества и итоговой суммой
- Избранное и сохранение в localStorage
- Toast-уведомления и модальные окна
- Промокод и форма обратной связи
- Отдельная страница с маленькими питомцами: хомяки, морские свинки, декоративные кролики
- Адаптация под планшеты и мобильные устройства

## Стек

- HTML
- CSS
- JavaScript

## Запуск

Откройте файл `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```
